# Burhan's studio

A buildless Three.js portfolio prototype with a scroll-driven studio tour, character animation blending and accessible project sections.

Run `python3 -m http.server 4175` and open http://localhost:4175/.

Read [CONTINUE.md](CONTINUE.md) for the design brief, implementation details, current limitations and next steps for Claude or another coding assistant.

The rigged character and walk animation are included at `outputs/burhan-character.glb`. Cloning this repository includes everything needed for the character preview.
